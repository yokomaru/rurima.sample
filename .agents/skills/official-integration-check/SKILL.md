# Official Integration Check

外部技術を利用する場合は、実装前に公式ドキュメントや公式リポジトリを確認する。

- 現行バージョンで推奨されている方法を確認する
- 非推奨・旧方式ではないか確認する
- 公式の公開API・CLI・手順がある場合はそれを優先する
- 内部APIや独自実装が必要な場合は、実装前に理由とリスクを説明する
- 重要な選択肢が複数ある場合は、実装前に推奨案と理由を示して相談する
- 確認できない点を推測で補わない
